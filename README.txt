P24 AVIATION FLOW TRAINER — CESSNA PUBLIC BETA

OVERVIEW
This is a multi-module interactive training prototype, not just Preflight Interior.
Current modules: Preflight Interior and Power Loss on Takeoff — On the Ground.
Holding Short is not part of this release.

LOCAL TESTING
1. Keep index.html, preflight.html, and emergency-on-takeoff.html together in one folder.
2. Open index.html in your browser.
3. Select a module and click to enable audio if your browser requires it.

GITHUB PAGES
Upload all three HTML files together to the publishing root of your GitHub Pages repository.
index.html is the landing page; it links to preflight.html and emergency-on-takeoff.html.
Do not publish private Creator Studio files.

WORDPRESS INSTALLATION (for WordPress sites that support custom plugin uploads)
The previous standalone P24_Aerospace_C172S_WordPress_Demo.zip package used the [c172_demo] shortcode and expected demo/index.html. That older installation process was for the preflight-only demo. It has NOT been verified for this multi-page release; the plugin may need updating to package and serve all three pages and preserve their relative links.
Do not assume that simply replacing demo/index.html will deploy the new modules.

SECURITY AND DISCLAIMER
Browser-delivered HTML, JavaScript, and embedded audio can be inspected or copied by site visitors. Keep private materials out of public hosting.
This is an unapproved educational study prototype, not an operational or emergency checklist. Some reference content comes from a 2025 Skyhawk 172N checklist and has not been validated for the 172S. Consult the aircraft-specific approved documents and an instructor.
