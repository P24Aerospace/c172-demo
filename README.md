# Plonky Works Flow Trainer

## Cessna 172 — Interactive Cockpit Training | Beta Prototype

**Practice the flow. Chair Fly Anywhere.**

Plonky Works Flow Trainer is a browser-based study prototype designed to help pilots rehearse cockpit procedures using interactive controls, audio guidance, and repetition. Students select a module on the landing page, interact with a simulated cockpit, and use an electronic checklist to review their actions.

## Available modules

### Preflight Interior
- Interactive analog-style cockpit and guided Preflight Interior sequence
- Passenger briefing with spoken and written content
- Simulated controls and electronic checklist verification
- Three-second blue control-location hints during guided practice
- Separate FLOW Recall exercise for unaided control-location practice

### Power Loss on Takeoff — On the Ground
- Simulated Runway 21 takeoff-roll scenario with power loss before rotation
- Narrated introduction, cockpit view throughout, engine/audio effects and checklist interaction
- Five-item study sequence; simulated rudder-pedal braking and control feedback
- Blue control-location hints after three seconds
- Simulated runway clearing by ground crew after stopping

## In development

## Project files

- `index.html` — module-selection landing page
- `preflight.html` — Preflight Interior interactive module
- `emergency-on-takeoff.html` — Power Loss on Takeoff (On the Ground) module

To test locally, keep these files in the same folder and open `index.html` in a browser. Audio playback may require a click to begin.

## Important disclaimer

**THIS PROJECT IS STILL IN DEVELOPMENT AND IS FOR EDUCATIONAL DEMONSTRATION PURPOSES ONLY.**

This prototype is not FAA-approved and must not be used for aircraft operations, flight planning, emergency decision-making, or as a substitute for professional flight instruction. It is not a replacement for the aircraft's approved Pilot's Operating Handbook (POH), Airplane Flight Manual (AFM), or applicable aircraft-specific checklists.

Some study material originated from a **2025 Skyhawk 172N checklist procedure** and has **not been validated for a Cessna 172S**. Performance indications, runway events, procedures, cockpit depictions, and interactive responses are simulated or simplified. Always consult the aircraft-specific approved documentation and a qualified flight instructor.
